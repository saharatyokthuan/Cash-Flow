# 💰 Cash-Flow — แอปบันทึกรายรับรายจ่าย

เว็บแอปจัดการการเงินส่วนตัวแบบ **Single Page Application** ทำงานได้ 100% บนเบราว์เซอร์
ไม่ต้องมีเซิร์ฟเวอร์ ไม่ต้องสมัครสมาชิก ข้อมูลเก็บไว้ในเครื่องคุณเองผ่าน `localStorage`

## ✨ ฟีเจอร์หลัก

| หน้า | ความสามารถ |
|---|---|
| 🏠 **หน้าแรก** | บันทึกรายรับ/รายจ่าย, กรองตามประเภทและบัญชี, แก้ไข/ลบรายการ |
| 💳 **บัญชี** | สร้างหลายกระเป๋าเงิน (เงินสด/ธนาคาร/e-Wallet), โอนเงินระหว่างบัญชี |
| 🤝 **เงินกู้** | ติดตามยอดยืม-คืนรายบุคคล พร้อมแถบความคืบหน้า |
| 📱 **ผ่อนชำระ** | จัดการรายการผ่อนมือถือ/PayNext, บันทึกจ่ายงวดทีละหลายงวด |
| 🏷️ **หมวดหมู่** | เพิ่ม/ลบ/รีเซ็ตหมวดหมู่ แยกฝั่งรายรับ-รายจ่าย |
| 📋 **ลิสต์ทูเพย์** | บิลและรายการประจำ พร้อมแจ้งเตือนเลยกำหนด + ทำซ้ำรายเดือน |
| 📊 **สรุป** | กราฟแท่ง 6 เดือนย้อนหลัง + กราฟโดนัทตามหมวดหมู่ (Canvas ล้วน) |
| 🔍 **ค้นหา** | ค้นหาจากชื่อ หมวดหมู่ หมายเหตุ หรือวันที่ พร้อมยอดรวมผลลัพธ์ |
| ⚙️ **ตั้งค่า** | นำเข้า/ส่งออก Excel, สำรองข้อมูล JSON, ล้างข้อมูล |

## 🚀 วิธีใช้งาน

### รันบนเครื่อง
```bash
git clone https://github.com/<your-username>/cash-flow.git
cd cash-flow
```
เปิด `index.html` ด้วยเบราว์เซอร์ได้เลย — หรือใช้ dev server เพื่อให้ทำงานได้สมบูรณ์:

```bash
npx serve .
# หรือ
python -m http.server 8000
```

### Deploy ฟรี
รองรับ static hosting ทุกเจ้า — **GitHub Pages**, **Netlify**, **Vercel**, **Cloudflare Pages**
แค่ push โฟลเดอร์ขึ้นไปก็ใช้งานได้ทันที ไม่ต้อง build

## 🗃️ โครงสร้างข้อมูล

ข้อมูลทั้งหมดเก็บใน `localStorage` ภายใต้คีย์ **`cashflow_v1`**

```javascript
{
  items: [           // รายการรายรับ-รายจ่าย
    { id, date, name, amount, type, category, wallet, note }
  ],
  wallets: [         // บัญชี/กระเป๋าเงิน
    { id, name, init }
  ],
  cats: {            // หมวดหมู่
    income:  ["เงินเดือน", "โบนัส", ...],
    expense: ["อาหาร", "เดินทาง", ...]
  },
  installments: [    // รายการผ่อน
    { id, type, name, total, monthly, terms, paid, date, note }
  ],
  bills: [           // บิล/รายการประจำ
    { id, name, amount, type, due, category, wallet, repeat, paid }
  ]
}
```

## 📥 นำเข้า / ส่งออก Excel

**คอลัมน์ที่รองรับ** (ภาษาไทยหรืออังกฤษก็ได้):

| คอลัมน์ | ตัวอย่าง | หมายเหตุ |
|---|---|---|
| วันที่ | `2026-09-07` | รองรับรูปแบบวันที่ของ Excel ด้วย |
| รายการ | `ข้าวมันไก่` | จำเป็น |
| ประเภท | `รายรับ` / `รายจ่าย` | ไม่ระบุ = รายจ่าย |
| หมวดหมู่ | `อาหาร` | ไม่ระบุ = อื่นๆ |
| บัญชี | `เงินสด` | ไม่ตรงกับที่มี = บัญชีแรก |
| จำนวนเงิน | `65` | จำเป็น ต้องมากกว่า 0 |
| หมายเหตุ | `มื้อเที่ยง` | ไม่บังคับ |

> ใช้ [SheetJS](https://sheetjs.com) ผ่าน CDN — ต้องเชื่อมต่ออินเทอร์เน็ตตอนนำเข้า/ส่งออก

## 💡 เกร็ดการใช้งาน

- **เงินกู้** คำนวณอัตโนมัติจากหมวด `ยืมเงิน` (รายรับ) และ `คืนเงินกู้` (รายจ่าย) โดยจับกลุ่มจาก**ชื่อรายการ = ชื่อคน**
- **โอนเงิน** สร้างรายการคู่ (รายจ่ายฝั่งต้นทาง + รายรับฝั่งปลายทาง) ยอดรวมจึงไม่บวม
- **บิลทำซ้ำ** เมื่อกดจ่าย ระบบจะเลื่อนวันครบกำหนดไปเดือนถัดไปให้เอง
- กด **Esc** เพื่อปิด modal หรือ sidebar ได้ทุกจุด

## ⚠️ ข้อควรระวัง

ข้อมูลอยู่ในเบราว์เซอร์เครื่องนี้เท่านั้น — **การล้าง cache/site data จะทำให้ข้อมูลหายถาวร**
แนะนำให้กด **"สำรองข้อมูล"** หรือ **ส่งออก Excel** เป็นประจำ
